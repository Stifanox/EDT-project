# N4 – Widok „Encje NER”

**Właściciel:** O3 · **Zależności:** !P0, ~N2 · **Status:** patrz [`PROGRESS.md`](../../PROGRESS.md)

## Cel
Lista wykrytych encji z filtrowaniem po typie, wyszukiwaniem encji i przeglądaniem dokumentów, w których występują.

## Zakres
- Wyszukiwarka encji (podciąg) + filtr typu (multiselect `EntityType`).
- Tabela encji: forma, typ, liczba wystąpień, liczba dokumentów (z `entity_stats`).
- Wybór encji → lista dokumentów (`doc_ids_with`) z fragmentami kontekstu (`mentions_of` + `entity_context_html`)
  i przyciskiem „Otwórz” (`nav.open_document`).
- Przycisk „Szukaj w tych dokumentach” → przejście do wyszukiwarki z ustawionym filtrem encji
  (klucz w `st.session_state` uzgodniony z O2, zapisany w dzienniku).
- Obsługa przejścia z widoku dokumentu (D5) z preselekcją encji: `nav.selected_entity()` → `(key, EntityType)`, po obsłużeniu `nav.clear_selected_entity()` (gotowe w `edt/ui/nav.py`).
