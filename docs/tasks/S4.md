# S4 – Wyszukiwanie semantyczne

**Właściciel:** O2 · **Zależności:** !P0 · **Status:** patrz [`PROGRESS.md`](../../PROGRESS.md)

## Cel
Znajdowanie dokumentów podobnych znaczeniowo do zapytania, także między językami (zapytanie PL ↔ dokument EN).

## Zakres
- Model `config.SEMANTIC_MODEL_NAME` (`sentence-transformers`, wielojęzyczny), ładowany leniwie raz na proces.
- **Chunking**: dokument dzielony na fragmenty (np. akapity lub okna ~200 słów z zakładką), embedding
  każdego fragmentu. Score dokumentu = max (lub średnia top-k) podobieństwa fragmentów.
- Snippet = najlepiej dopasowany fragment (podświetlenia mogą być puste albo obejmować cały fragment w kontekście).
- Cache embeddingów na dysku (`config.CACHE_DIR / "embeddings"`, klucz = `content_hash` + nazwa modelu),
  żeby restart nie przeliczał korpusu.
- Próg minimalnego podobieństwa (np. 0.2), żeby nie zwracać „wszystkiego” (kontrakt: score > 0).
