# N2 – Trwały indeks encji (SQLite)

**Właściciel:** O3 · **Zależności:** !P0, ~N1 · **Status:** patrz [`PROGRESS.md`](../../PROGRESS.md)

## Cel
Encje liczone raz (NER jest wolny) i przechowywane między uruchomieniami. Szybkie zapytania dla widoków i filtrów.

## Zakres
- `SqliteEntityIndex(conn, extractor)` implementujący `EntityIndex`.
- Tabela `entities(doc_id, text, normalized, label, raw_label, start, end)` + indeksy na `(normalized, label)`, `doc_id`, `label`.
- Tabela `entity_docs_state(doc_id, content_hash, extractor_version)`: `rebuild()` przelicza
  **tylko** dokumenty nowe lub zmienione (inna wersja ekstraktora → ponownie).
- Agregaty `entity_stats` w SQL (`GROUP BY normalized, label`).
